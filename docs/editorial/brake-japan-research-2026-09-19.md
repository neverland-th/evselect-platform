# ENDLESS: ทางเลือกญี่ปุ่นสำหรับบทความเบรก EV

ตรวจแหล่งต้นทางและภาพจริง 19 กันยายน 2026. งานนี้ใช้ข้อมูลจาก ENDLESS Japan และ Endless Brake Technology Europe เท่านั้น ไม่มีการรับรอง fitment ของรถไทย ไม่มีใบเสนอราคา และไม่มีการทดสอบผลิตภัณฑ์โดย EVSELECT

## แนะนำการจัดเนื้อหา

เพิ่ม ENDLESS เป็นตัวอย่างการเลือก **compound ให้ตรงการใช้งาน** และ **ซื้อคาลิปเปอร์/จานเป็นระบบที่เข้ากันได้** ไม่จัดเป็นบันได “ราคาแพงกว่าจึงหยุดสั้นกว่าเสมอ”. สี่กลุ่มหลักที่มีบทบาทต่างกันชัดเจนคือ SSM PLUS, MX72, MX72 PLUS และชุด 6POT / RacingMONO6 ที่ออกแบบตรงรถ ส่วน SSS และ CC-Rg ใช้เป็นตัวเปรียบเทียบเมื่อผู้อ่านต้องการ bite หรือเน้นสนามมากขึ้น

## ผ้าเบรก: ตัวเลขที่ผู้ผลิตระบุ

ช่วงอุณหภูมิในตารางคือ **ช่วงอุณหภูมิโรเตอร์ที่ผู้ผลิตระบุว่าเหมาะกับผ้า compound นั้น** ไม่ใช่อุณหภูมิที่รถบ้านต้องทำให้ถึง ไม่ใช่ผลทดสอบของ EVSELECT และไม่บอก brake distance หรือแรงม้าสูงสุดที่รองรับ ค่าสัมประสิทธิ์ μ ของต่างแบรนด์/วิธีทดสอบไม่ใช่คะแนนเปรียบเทียบแบบตรงตัว

## คาลิปเปอร์/จาน: สองแนวทางที่มีตัวตนจริง

### ENDLESS 6POT — คาลิปเปอร์ forged สำหรับชุดตรงรุ่น

ผู้ผลิตวาง 6POT เป็นทางเลือกที่เน้นความคุ้มค่าในตระกูลคาลิปเปอร์ใหญ่ ใช้ forged aluminium, น้ำหนักคาลิปเปอร์ที่ระบุ 3,280 g, รองรับเส้นผ่านศูนย์กลางจานในช่วง 320–370 mm และสีน้ำเงิน anodized เป็นสีมาตรฐาน. คำว่า “ล้อ 17 นิ้วขึ้นไป” ในหน้าไม่รับประกันว่าจะใส่ได้ทุกวง ต้องตรวจรุ่นล้อ/ขนาด/offset และ template จริง. [ENDLESS — 6POT](https://www.endless-sport.co.jp/products/brake_caliper/index_6POT.html)

หน้า 6POT ระบุว่า kit อาจใช้จานเดิม, จานหนึ่งชิ้น หรือสองชิ้นตาม application. ส่วนประกอบหลักประกอบด้วยคาลิปเปอร์ ผ้า สาย และ bracket; จานไม่รวมใน brake kit ที่ใช้จานเดิม. สั่ง compound ได้ โดย MX72 เป็น default เมื่อไม่ระบุ. จึงควรขอใบเสนอราคาและรายการชิ้นส่วนครบชุด ไม่ซื้อ “6 pot” จากจำนวนลูกสูบอย่างเดียว. [แหล่งเดียวกัน](https://www.endless-sport.co.jp/products/brake_caliper/index_6POT.html)

### ENDLESS RacingMONO6 — ทางเลือก monoblock สำหรับคนเน้นสุด

ผู้ผลิตระบุ forged monoblock, น้ำหนักคาลิปเปอร์ 2,930 g, จาน 355–390 mm และผิว hard anodized. เป็นตัวอย่างว่า “เน้นสุด” มีทางเลือกชุดจานโลหะกับคาลิปเปอร์ระดับสูงด้วย ไม่ได้มีแต่ carbon ceramic. ไม่ควรเทียบเลขน้ำหนักกับ 6POT แล้วสรุปประสิทธิภาพระบบทันที เพราะขนาด จาน และ application ต่างกัน. [ENDLESS — RacingMONO6](https://www.endless-sport.co.jp/products/brake_caliper/index_RacingMONO6.html)

การสั่ง kit ที่ถูกต้องตามผู้ผลิต: ตรวจ application → ตรวจ wheel clearance โดยใช้ template ขนาดจริง/ข้อมูลล้อ → ระบุ compound. รถที่ไม่มีในรายการอาจทำ custom ได้บางกรณี แต่ต้องยืนยันเป็นรายคัน ไม่ใช่ใบรับรองทั่วไป. [ENDLESS — วิธีสั่ง kit](https://www.endless-sport.co.jp/products/brake_caliper/index_caliper_howtobuy.html)

## Tesla fitment: Data unavailable

ตรวจ [Japan caliper application list](https://www.endless-sport.co.jp/products/brake_caliper/car_list.html), [Japan pad application list](https://www.endless-sport.co.jp/products/brake_pad/car_list.html), หน้า Europe brake kits และค้นชื่อ Tesla/Model 3/テスラ ในโดเมนต้นทาง. ในรายการที่ตรวจไม่พบหลักฐานที่ยืนยัน brake kit/pad part number สำหรับ Tesla พร้อม exact year/trim/market ที่ใช้กับรถไทย

ผลค้น Tesla Model 3 บนโดเมน Japan พบไฟล์ suspension IMPORT.pdf ของ FUNCTION .COM แต่เป็น **โช้ค** จึงห้ามนำไปอ้าง fitment เบรก. การไม่พบในรายการไม่ได้แปลว่า ENDLESS ทำให้ไม่ได้; หมายความว่ายังไม่ควรเขียนว่า “ชุดนี้ใส่ Model 3 Highland / Performance ไทยได้ตรงรุ่น” จนกว่าจะมี confirmation ของชิ้นส่วนและรถจริง

ยังไม่ยืนยัน fitment สำหรับ BYD/Zeekr/EV อื่น ราคาไทยรวมติดตั้ง stock และ warranty: **Data unavailable**. รูปในบทความต้องใช้คำว่า “ตัวอย่างผลิตภัณฑ์” ไม่อ้างว่าเป็น kit ของ Tesla ที่ยืนยันแล้ว

## Compatibility ที่บทความไม่ควรมองข้าม

**คำว่า ceramic carbon metal ในชื่อวัสดุผ้า ไม่ได้บอกว่าผ้านั้นใช้กับจาน carbon ceramic ได้**. ENDLESS Europe แยก compound สำหรับ CCM โดยเฉพาะ ได้แก่ CCD-A สำหรับถนนและสนาม, CCD-P สำหรับถนน, CCD-R สำหรับสนาม. ต้องยึด approved pairing ของจานและผ้า ไม่เลือก MX72/SSM PLUS เพียงเพราะชื่อหรือค่าอุณหภูมิ. [Endless Europe — For CCM discs](https://endless-brake.info/products/brake-pads/for-ccm-discs/)

ENDLESS Japan มีคำเตือนเฉพาะ SSY/SSS/SSM PLUS กับผิวจานที่เคลือบกันสนิม: coating อาจติดบนหน้าผ้าและทำให้เสียหายหากเตรียมผิวไม่ถูกต้อง จึงต้องให้ผู้ติดตั้งทำตามคำแนะนำของจานและผ้า. ไม่สรุปเป็นคำแนะนำให้เจ้าของรถขัดจานเอง และไม่เหมารวมว่าจาน coated ทุกชนิดควรเอา coating ออก เพราะบางระบบออกแบบให้ใช้เป็นคู่โดยเฉพาะ. [ENDLESS — Coated rotor caution](https://www.endless-sport.co.jp/products/brake_pad/caution_antiRust.html)

ไม่เสนอ ENDLESS pad สลับเข้า Brembo EV disc โดยอัตโนมัติ: ผู้ผลิต Brembo ระบุให้จับคู่ EV disc กับ EV pad ของระบบนั้น (อ้างในบันทึก thermal research เดิม)

สำหรับ fluid: เลือกให้ตรงข้อกำหนดของผู้ผลิตรถและชุดเบรก รวมมาตรฐาน/ความหนืด/ซีล ไม่เลือกจากจุดเดือดสูงอย่างเดียว. RF-650 เป็นตัวอย่างน้ำมัน performance ของ ENDLESS แต่หน้าเว็บนี้ไม่ได้ยืนยัน Tesla approval. ข้อมูลล่าสุดใน specification เป็น **dry 320°C / wet 218°C** และมีหมายเหตุปรับการรายงาน dry point; prose ตอนท้ายยังเขียน 323°C จึงควรยึดกล่อง specification หรือไม่ใส่ตัวเลขในบทความหากไม่ได้จำเป็นต่อการตัดสินใจ. [ENDLESS — RF-650](https://www.endless-sport.co.jp/products/chemical/index_rf650_series.html)
