ฉบับ 19 กันยายน 2569 | ไม่ใช่รายการรับรองสินค้า/ผู้ติดตั้ง

สวัสดีครับ/ค่ะ ขอข้อมูลชุดช่วงล่างที่เหมาะกับรถและการใช้งานนี้
รถ: [ยี่ห้อ / รุ่น / ปี / รุ่นย่อย / ตลาดไทยหรือรถนำเข้า]
ช่วงล่างเดิม: [ปรับมือ / ปรับไฟฟ้า / ยังไม่ทราบ]
ล้อและยาง: [ขนาด / Offset / รุ่นยาง / ลมยางตามข้อมูลรถ]
โหลดประจำ: [ผู้โดยสาร / สัมภาระ / อุปกรณ์เพิ่ม]
การใช้งาน: [ถนนประจำ / ทางขึ้นอาคาร / สนามปิด]
อาการหรือเป้าหมายหลัก: [ระบุอย่างเดียวก่อน]
เหตุการณ์ที่พบ: [แรงกระแทกครั้งแรก / เด้งตาม / โยนตัว / อื่น ๆ พร้อมผิวทาง]
สิ่งที่ยอมแลกไม่ได้: [ความสูงใต้ท้อง / เสียง / ความสบาย / อื่น ๆ]
งบรวมสินค้าและบริการ: [ระบุงบ โดยยังไม่ใช่ราคาเสนอของ EVSELECT]
เกณฑ์ประเมินที่ตกลง: [อาการใดควรดีขึ้น / อะไรต้องไม่แย่ลง / เงื่อนไขทดลองปลอดภัย]
ไม่ต้องส่งเลขตัวถังเต็มหรือข้อมูลส่วนตัวในขั้นสอบถามทั่วไป

ตัวอย่างโจทย์สมมติ:
ต้องการลดแรงสะเทือนครั้งแรกที่รอยต่อสำหรับผู้โดยสารหลัง โดยไม่เพิ่มการโยนซ้ำ
และยังผ่านทางลาดบ้านได้ ขอเหตุผลที่เลือกชุด พร้อมข้อแลกเปลี่ยนและวิธีตรวจผล
ตัวอย่างนี้ไม่ใช่ผลทดสอบหรือคำรับรองว่ามีชุดใดทำได้ครบทุกข้อ

ขอคำตอบพร้อมเอกสารก่อนตกลงซื้อ:
1) ยี่ห้อ ซีรีส์ รหัสสินค้าครบชุด รุ่นปรับปรุง และคู่มือติดตั้งฉบับใด?
2) ผู้ผลิตระบุรองรับปี รุ่นย่อย ตลาด และระบบช่วงล่างเดิมนี้ตรงไหน?
   เมื่อผ่านเรื่องตรงรุ่นแล้ว อะไรยืนยันว่าลักษณะชุดเหมาะกับอาการ ถนน และโหลดของฉัน?
3) น้ำหนักเพลาที่รองรับและโหลดใช้งานอยู่ในข้อกำหนดหรือไม่?
4) มีช่องแรงหน่วงอะไรจริง: ปรับร่วม / Rebound / Compression / LSC / HSC?
   จำนวนคลิกเป็นอีกข้อมูลหนึ่ง ไม่ให้นับความสูงหรือ Preload เป็น Way
5) สปริงรหัสอะไร อัตราสปริงและหน่วยใด เหตุผลที่เลือกเหมาะกับรถนี้คืออะไร?
   หากเปลี่ยน Spring rate ต้องปรับ Valving หรือมีข้อจำกัดของชุดเดิมหรือไม่?
6) ช่วงความสูง ระยะยุบ–ยืด Bump stop และระยะเคลียร์ต้องตรวจอะไร?
   หากสปริงหลังแยกจากโช้ค ขอวิธีตั้งความสูงและความยาวโช้คเฉพาะชุด
7) ถ้ามีระบบปรับไฟฟ้าเดิม ชุดนี้รักษาหรือเปลี่ยนการทำงานอย่างไร?
   ขอเอกสารความเข้ากันได้ ไม่ใช้การไม่มีไฟเตือนอย่างเดียวเป็นหลักฐาน
8) ค่าตั้งต้น วิธีนับคลิกจากด้านใด และบันทึกทั้งสี่มุมจะได้รับเมื่อใด?
9) ราคาครอบคลุมติดตั้ง ตั้งศูนย์ ตรวจระยะ และตรวจซ้ำหรือไม่?
   ตรวจจุดยึดบูชยาง (Bonded rubber bush) และขันที่ระดับ/แรงขันตามคู่มือรถหรือไม่?
   ขอค่าความสูงกับจุดวัด ใบตั้งศูนย์ และค่าตั้งสี่มุมตอนส่งมอบ
   ขอใบเสนอราคาแยกสินค้า/บริการ/ภาษี และวันหมดอายุราคา
10) สต็อกจริงหรือสั่งนำเข้า ระยะเวลายืนยันได้หรือยัง เงื่อนไขคืน/ยกเลิกเป็นอย่างไร?
11) การรับประกันที่ใช้ได้ในไทยคืออะไร ใครรับผิดชอบ อะไหล่/ซ่อมมีตามรหัสนี้หรือไม่?
12) หากติดตั้งแล้วมีเสียง รั่ว เสียดสี หรือการควบคุมผิดปกติ ขั้นตอนหยุดใช้และตรวจคืออะไร?

ถ้ารายการใดยังไม่มีหลักฐาน ให้ระบุ “ต้องยืนยัน” พร้อมผู้รับผิดชอบและวิธีตรวจ
ไม่ใช้ภาพสินค้า ชื่อรุ่นรถคล้ายกัน หรือคำว่าใส่ได้แทนเอกสารรหัสสินค้าจริง
